A JavaFX-based math quiz game built for a Software Engineering course project.


## OVERVIEW
The game challenges players with timed arithmetic questions, optional binary-mode gameplay, score tracking, combo mechanics, and a leaderboard, built with PostgreSQL JDBC.


## TECH STACK
- Java 21
- JavaFX 21
- Maven
- PostgreSQL
- BootstrapFX, ControlsFX, and various JavaFX utility libraries
